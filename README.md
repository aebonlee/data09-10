내 PC에서 쓰려면 설치 없이 아래 두 방법 중 하나로 엽니다.

1. **파일로 바로 열기** — 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(엑셀 라이브러리도 `vendor/` 에 들어 있습니다).
2. **간이 서버로 열기** — 폴더에서 `python3 -m http.server 8000` 을 실행하고 브라우저에서 `http://localhost:8000` 을 엽니다.

처음 열면 **시작 화면(00 Home)** 이 나옵니다 — 10단계 작업 흐름·지금 자료 상태·과제 B(data09-27) 링크가 한 화면에 있습니다(2026-09-30 저녁). 데이터는 비어 있습니다. 「06 가져오기·내보내기」의 **「예시 데이터 불러오기」** 를 누르면 시연용 가상 모델 15건(평가 점수 포함)·Scope 1개·운영 루프 이력 1건이 들어가고, 화면 위에 「예시 데이터」 안내 띠가 표시됩니다.

- 예시 데이터는 **모두 가상**입니다. 모델명은 「예시-」로 시작하고, 제원·색·출처(example.com)·이미지(도형 SVG)는 시연용으로 만든 값입니다. 브랜드 칸만 부록 B 경쟁사 이름을 빌렸고, 그 회사의 실제 제품 정보가 아닙니다.
- 데이터는 **이 브라우저(localStorage)에만** 저장됩니다. 이미지는 긴 변 800px(설정 가능)로 줄여 보관하며, 브라우저 한도(대개 5MB 안팎)가 있으니 「JSON 백업(이미지 포함)」으로 나눠 보관하세요.
- 예시 파일(`samples/`, 모두 가상): `예시데이터_사내정리표.xlsx`·`.csv`(열 이름이 표준 Schema 와 다른 정리표 — 열 연결 연습용), `예시데이터_모델목록.xlsx`(이 도구의 내보내기 형식)
- 로직 테스트: `node test/logic.test.mjs` (의존성 없음 — 과제 B 테스트 `test/report-logic.test.mjs`, 공용 AI 연결 테스트 `test/ai-endpoint.test.mjs` 도 함께 돌립니다)

### 쓰는 순서

1. **01 Scope Setup** — Product Type → Tonnage(부록 C) → 경쟁사(부록 B 13개사 + Mecalac) → Purpose 를 고르고 「범위 확정」. Scope ID 가 만들어지고 위쪽 칩에 표시됩니다.
2. **05 자료 등록** 또는 **06 가져오기** — 모델을 한 건씩 넣거나, 기존 엑셀 정리표를 열 연결로 한꺼번에 넣습니다.
3. **02 Status Dashboard** — 브랜드 × Tonnage 보유 현황, View 보유 현황, 필수 메타 누락을 확인하고 「보완」합니다.
4. **03 Card Gallery** — 필터로 좁혀 비교할 모델을 2~4개 담습니다.
5. **04 Side-by-Side** — 같은 View 끼리 이미지를 맞대고 비교표를 Excel·인쇄용 PDF 로 내보냅니다.
6. **07 Insight** — 「비중 조정」에서 리포트 목적을 고르고 막대·숫자로 8기준 비중을 바꿉니다(나머지가 자동으로 맞춰져 합계 늘 100%, 「내 비중으로 저장」하면 이름 붙은 프로필로 버전이 쌓임 — 08 Report 화면에도 같은 패널), Radar Chart 로 브랜드별 8기준을 겹쳐 봅니다. 브랜드별 요약·평가표(8기준 × 브랜드)·강약점·Design Tag 트렌드·White Space 를 봅니다. 평가는 수강생 평가 기준 자료의 **8기준(비중 합 100%)·1~5점**(1 개선 필요 ~ 5 Benchmark 수준)이고, 디자이너 점수는 이 화면 아래 「디자인 평가 — 모델별 8기준 점수」 표에서, AI 점수·근거/코멘트는 자료 등록의 「Design Evaluation」 블록에서 넣습니다. 가중 점수와 Insight 는 이 점수로 계산합니다. 요약 코멘트는 직접 쓰거나 AI 요약(프롬프트 복사 → 답 붙여 넣기, 또는 AI 연결 설정 후 「설정한 AI 서버로 보내기」)을 저장합니다.
7. **08 Benchmarking Report** — 10개 항목 보고서(2번 디자인 평가 + 3~6번 평가 기반 Insight)를 인쇄·PDF 저장하거나 xlsx·HTML 로 내려받습니다.
8. **09 전문가 피드백** — 리포트 항목·모델별로 평가(1~5)와 코멘트를 남기고, 반영하면 「반영됨」으로 바꿉니다.
9. **10 운영 루프** — 업데이트 주기(기본 주간)와 오래된 자료 기준(기본 수집일 기준 20년)을 정하고 한 바퀴 단계를 체크한 뒤 「이번 사이클 완료」를 누릅니다. 예정일이 지나거나 오래된 자료가 있으면 왼쪽 메뉴에 표시됩니다.

### Outlook 메일을 넣는 방법

- **클래식 Outlook — 폴더째(권장)**: [`tools/outlook/Export-OutlookMail.ps1`](tools/outlook/README.md) 를 내 PC 에서 실행하면 고른 Outlook 메일 폴더(받은 편지함·하위 폴더·보낸 편지함)의 기간 안 메일을 `.eml` 로 저장합니다. 읽기 전용이고 네트워크를 쓰지 않으며, 첨부는 이름·크기만 적습니다. 「대상 메일 폴더」는 디스크 경로가 아니라 Outlook 안의 폴더입니다.
- 새 Outlook · 웹 Outlook: 메일을 열고 「…」 → 「다운로드」(또는 「다른 이름으로 저장」) → `.eml`.
- 클래식 Outlook: 끌어 놓으면 `.msg` 가 됩니다. `.msg` 는 브라우저가 읽을 수 없어 「파일 → 다른 이름으로 저장 → 텍스트 전용(.txt)」으로 저장해 불러오거나, 메일 내용을 복사해 「붙여 넣기」 칸에 넣어 주세요.

### 쓰는 순서

1. **01 보고 설정** — 주간/월간, 기준일(이 날이 속한 주·달), 주 시작 요일, 프로젝트·키워드·Business Group, 주간 양식 표 문체(개조식/원문), AI 연결 설정(선택 — 사내 LLM).
2. **02 메일·자료 입력** — .eml 여러 개를 불러오거나 끌어 놓습니다. 제목·보낸이·날짜·첨부 이름을 읽고, 보고 기간 안/밖을 표시합니다. ID(E001…)를 누르면 원문을 봅니다.
3. **03 업무 그룹** — RE:/FW: 를 뗀 제목·회신 흐름·키워드로 묶은 업무와 현재 상태·변화 이력. 잘못 묶인 프로젝트는 바꿉니다.
4. **04 실적·계획·이슈** — 「규칙으로 분류」로 1차 항목을 뽑고, 필요하면 AI 반자동(프롬프트 복사 → 회사가 허용한 AI 에 붙여 넣기 → JSON 답 붙여 넣기) 또는 「설정한 AI 서버로 보내기」(사내 OpenAI 호환 LLM)로 보강합니다. 모든 항목에 근거 메일이 붙고, 완료가 분명하지 않은 것은 「확인 필요」입니다. 표에서 고치고 「확인」 표시를 남깁니다.
5. **05 이전 계획 대비** — 지난 보고서 계획(승인 이력 또는 붙여 넣기)이 완료·진행·지연·이월인지 제안을 보고 확정합니다.
6. **06 보고서 초안** — 주간(맨 앞 **양식 표**: Business Group · 프로젝트명 · 금주 실적 · 차주 계획, 그 아래 실적·차주 계획·이슈 상세) / 월간(요약·실적·상태·차월 계획·이슈·의사결정) 초안. 근거 ID 를 누르면 원문 메일. 「승인하고 이력에 남기기」 후 Word(.docx·.doc)·Excel·인쇄(PDF)·HTML 로 내려받습니다. 메일 발송은 하지 않습니다.
7. **07 이력·백업** — 승인 이력, JSON 백업·복원.
